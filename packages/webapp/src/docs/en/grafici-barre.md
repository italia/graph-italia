# Bar chart

The bar chart compares values across categories, for example: cases by region, amounts by institution, applications by year.

## When to use it

- To compare a few dozen categories at most;
- for rankings and distributions;
- to compare several series on the same category (side-by-side or stacked bars).

## How to create the chart

1. Go to **Create new**, select **Chart** and load your data (see [Loading data](/docs/caricare-dati) for more details).
2. Choose the category column and one or more numeric series.
3. In **Configure the chart**, select **Bar chart**.

## Main settings

- **Direction**: whether the bars are vertical or horizontal. Horizontal bar charts are easier to read when the category labels are long or there are many categories;
- **Stack values**: adds the bars up into a single column to show the total and its composition on a chart with several series;
- **Logarithmic scale**: useful when the values span very different orders of magnitude (note: it makes visual comparisons less intuitive; the tooltip always shows the actual value);
- **Palette**, **legend** and its position, chart **height**;
- **Advanced settings**: tooltip, grid and axes (labels and contextual explanations, margins, value formatting).

## Tips

- If you need a ranking, sort the data in the source file before loading it: the chart follows the row order;
- if the chart has many categories, consider the horizontal direction and a greater height.
