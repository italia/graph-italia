# Tools

The **Tools** menu gathers features that do not require an account.

## Generate Data

Creates a test CSV file with random columns and rows: useful for exploring the editor before you have real data. You can download the file as CSV and use it as a dataset when creating a chart.

## Generate Pois

Creates a dataset of coordinates (latitude and longitude) on the Italian territory, ready for a point map.

## Check GeoJSon File

Upload a GeoJSON file and check its contents on a map before using it: boundaries, geometries and properties.

## Examples

The **Sample datasets** item in the navigation bar shows ready-made charts built with sample data: a good starting point to understand what you can create with Graph Italia.
