# Dashboard

A dashboard gathers several items and texts in a single page to share with one link.

## When to use it

The dashboard is very effective when you need to collect several charts and different pieces of information on a single page to share.

## How to create a dashboard

1. Go to **Create new**, select **Dashboard** and give it a title.
2. In the editor, add **slots** to the grid: each slot holds a chart, a map, a KPI group or a text block.

## How the grid is organised

- Each slot has a width of **1/3, 2/3 or full** and a height in rows;
- Drag the slots by their handle to reorder them, resize them from the bottom-right corner;
- On small screens the slots automatically stack at full width.

## How to use text blocks

Use text blocks to add introductions, methodological notes and remarks to the dashboard. Text blocks are written in **markdown** (headings, bold, lists, links). On the public page, full-width texts take up only the space they need.

## Saving and sharing

- Click **Save** to keep the layout and contents of your dashboard. Slots left empty on the grid are not saved;
- the public dashboard can be reached from the link in the **My dashboards** list and can be embedded in another site;
- the charts shown in the dashboard are the ones previously saved on Graph Italia and are updated automatically when the chart changes.
