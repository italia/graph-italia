# Pie chart

The pie (or donut) chart shows the shares of a total: how a whole is split among its parts.

## When to use it

- For charts with percentage breakdowns with **few entries** (ideally fewer than 7 slices);
- for charts whose total has a concrete meaning that you want to show in the centre.

Please note: if the chart has many entries or the values are close to each other, a horizontal bar chart is almost always easier to read.

## How to create the chart

1. Go to **Create new**, select **Chart** and load your data (see [Loading data](/docs/caricare-dati) for more details).
2. Choose the category column (it will be the slices) and **one** numeric series (the size of the slices).
3. In **Configure the chart**, select **Pie chart**.

## Main settings

- Show the **total** in the centre of the pie with a customisable label;
- set the **labels** on the slices or the **legend** (top, right, bottom);
- set the colour **palette**;
- tooltip with value and percentage of the slice under the cursor.
